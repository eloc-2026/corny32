# Image Assets for Super Smash Bros Quiz

This directory contains image assets for the image-based quiz questions.

## Directory Structure

```
public/images/
├── characters/     # Character portraits/renders
└── stages/         # Stage screenshots
```

## Image Requirements

- **Format:** PNG recommended (JPG also works)
- **Size:** 400-800px width recommended for optimal display
- **Aspect Ratio:** Any (images are auto-scaled to fit)
- **Background:** Transparent PNG preferred for characters

## Finding Images

You can find high-quality Smash Bros images from:
- Official Super Smash Bros. Ultimate website
- SmashWiki (https://www.ssbwiki.com/)
- Nintendo press kits
- Fan wikis and databases

## Placeholder Images

Until you add actual images, the quiz will still work but won't display images for these questions. The game will show a console warning if an image is missing.

## Testing

After adding images, reload the game and select "Characters (Images)" or "Stages (Images)" categories to test them.
